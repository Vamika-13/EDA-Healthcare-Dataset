# EDA-Healthcare-Dataset
This repository contains an exploratory data analysis (EDA) performed on a healthcare dataset consisting of over 55,000 patient records from multiple hospitals. The project demonstrates how Python and PySpark can be used to derive insights from structured health data.

# Project Overview
The dataset includes fields such as:
Patient demographics (age, gender)
Diagnosed medical conditions
Admission types (elective, emergency, urgent)
Billing amounts
Medication prescribed
Test results
Year of admission

The goal of this project was to clean, process and analyze the data to uncover patterns related to:
Age and gender distribution of medical conditions
Hospitalization and admission trends
Billing trends across conditions
Medication usage by diagnosis
Test result outcomes
Year-over-year patient volume

# Tools & Libraries Used
Databricks | PySpark | Python | Pandas | Matplotlib
